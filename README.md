\# IoT Health Monitoring System



An intelligent IoT system for remote health monitoring using Arduino, Wokwi, Node-RED, Python and Machine Learning.



\## Main Features



\* Real-time collection of health data

\* Arduino-based sensor simulation with Wokwi

\* Data transmission and visualization using Node-RED

\* Patient data generation and processing with Python

\* Machine Learning model for health-state prediction

\* Automatic detection of normal, stressful and critical conditions



\## Technologies



\* Arduino / C++

\* Wokwi

\* Python

\* Machine Learning

\* Node-RED

\* JSON



\## Project Structure



\* `Code\_Arduino\_\&\_Simulation\_With\_Wokwi/`: Arduino code and Wokwi simulation

\* `Scripts\_IA\_With\_Python\_Prediction/`: dataset generation, model training and prediction API

\* `flows.json`: Node-RED workflow

\* `Rapport\_IOT.pdf`: complete project report
